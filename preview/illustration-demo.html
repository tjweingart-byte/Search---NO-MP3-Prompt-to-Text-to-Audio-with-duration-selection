The whole mechanism: the server sends one d attribute with exactly one M. The client measures it with getTotalLength() and sets stroke-dashoffset = L × (1 − currentTime / duration). Because it reads the audio's own clock, seeking and buffering stay in sync for free — there is no timer to drift.
