The same words through every voice, so the only thing that differs is the voice. No model call, and no API key needed.

The honest test — Claude writes a real FAM script and the voice reads it. Asking the same question again in another voice reuses the cached script, so the comparison is the same words and the second one is free.

Every run also prints a line in the terminal, with the engine, the time to the first sentence and how far ahead of playback it ran.
A voice that sounds right but runs slower than about 3x realtime cannot ship — the pipeline speaks while it writes, and it has to stay ahead.
